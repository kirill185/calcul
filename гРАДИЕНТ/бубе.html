🎯 Цель и задачи проекта

Цель

Создать визуальный редактор для генерации CSS градиентов с возможностью экспорта в PNG

Актуальность

Веб-разработчики часто используют градиенты, но писать CSS вручную - трудоемко. Генератор ускоряет процесс.

Задачи

  • ✅ Разработать визуальный редактор градиента
  • ✅ Реализовать добавление/удаление цветовых остановок
  • ✅ Сделать автоматическую генерацию CSS кода
  • ✅ Добавить экспорт градиента в PNG
  • ✅ Написать тесты с покрытием 80%+ кода

📦 Класс ColorStop
├── Color Color { get; set; } // RGB + Alpha
├── double Position { get; set; } // 0% - 100%
└── ToString() // "Red (255,0,0) - 50%"

📦 Класс GradientData
├── GradientType Type // Linear / Radial
├── double Angle // 0-360°
├── List<ColorStop> Stops // Список остановок
├── AddStop() // Добавить цвет
├── RemoveStop() // Удалить цвет
├── SortStops() // Сортировка
└── GenerateCSS() // Генерация CSS

🖥️ Класс Form1 (UI)
├── Отрисовка градиента

Радиальный градиент
